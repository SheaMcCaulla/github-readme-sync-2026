title: 翻译演示
---
在遥远的地方，在单词山脉的背后，远离元音国和辅音国，生活着盲文本。它们分散地居住在书签林，就在语义洋——一片辽阔的语言海洋的海岸边。一条名为杜登的小河从它们居住的地方流过，为那里提供所需的规则养分。那是一个如天堂般的国度，在那里，烤熟的句子片段会直接飞进你的嘴里。即使是无所不能的标点也无法控制盲文本，那几乎是一种不受拼写规则约束的生活。然而有一天，一个名叫“罗勒姆·伊普萨姆”（Lorem Ipsum）的小盲文本行决定动身前往遥远的语法世界。大奥克斯莫克斯劝她不要去，因为那里有成千上万个邪恶的逗号、狂野的问号和狡猾的分号，但小盲文本没有听。她收拾好自己的七个大写字母，把首字母插进腰带，便上路了。当她到达斜体山脉的第一座山丘时，她最后一次回望了家乡书签林的天际线、字母村的标题以及她自己那条路——行巷的副标题。一个可怜的修辞性疑问流下了她的脸颊，然后
